# 🛡️ PassShield - Password Strength Analyzer & Generator

PassShield is a modern, real-time cyber-security web application built with React and Vite. It analyzes password security, detects compromised/leaked credentials, calculates brute-force crack times, and helps users generate safe, strong passwords.

## ✨ Features
- 🔍 **Real-Time Strength Checker**: Live evaluation of password length, case sensitivity, numbers, and special symbols.
- ⏱️ **Crack-Time Estimation**: Calculates estimated time required to crack the password.
- 🚨 **Breach Detector**: Alerts users if the entered password matches commonly compromised passwords.
- ⚡ **Custom Password Generator**: Generate memorable or ultra-complex passwords customized with your name and favorite numbers.
- 💡 **Security Best Practices**: Helpful guidelines and recommendations for robust credentials.
- ❓ **Interactive FAQ Accordion**: Common questions and answers about cybersecurity.
- 🌓 **Dark & Light Mode**: Seamless theme toggle for optimal viewing.

## 🛠️ Tech Stack
- **React.js**
- **Vite**
- **CSS3 / Responsive UI**
